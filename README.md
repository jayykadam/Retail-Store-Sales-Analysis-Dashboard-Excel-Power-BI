# Retail Store Sales Analysis Dashboard

## Project Overview
This project analyzes retail store sales data using Excel and Power BI. The dashboard provides insights into sales performance, profit trends, customer behavior, product categories, and regional performance.

## Tools Used
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Visualization

## Key Features
- Sales KPI Tracking
- Profit Analysis
- Category-wise Performance
- Regional Sales Analysis
- Interactive Filters and Slicers
- Business Insights Dashboard

## Process
1. Collected and cleaned the dataset in Excel.
2. Performed data preprocessing and formatting.
3. Imported data into Power BI.
4. Created data model and relationships.
5. Built interactive visualizations and KPI cards.
6. Added slicers and filters for dynamic analysis.
7. Designed a professional dashboard for business insights.

## Dashboard Insights
- Top-performing product categories
- High and low sales regions
- Profit trends across different segments
- Overall business performance metrics
